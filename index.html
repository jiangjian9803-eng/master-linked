Contact out with ChatGPT

把 ContactOut 官方 MCP 连接到 ChatGPT

CO
ContactOut MCP官方远程 MCP · 无需在本站保存 API key

三分钟安装（已验证）

  1. 使用安装了 Codex CLI 的 ChatGPT 桌面版；在 Settings → Security and login 中打开 Developer mode。
  2. 打开终端，依次运行下面两条命令。它们会添加公开插件源并安装 ContactOut 插件。
  3. 完全退出并重新打开 ChatGPT，然后前往 Settings → Plugins → Installed，确认出现 ContactOut with ChatGPT。
  4. 新建聊天并首次调用 ContactOut；出现授权页面时，再输入你自己的 ContactOut API token。
codex plugin marketplace add jiangjian9803-eng/contactout-chatgpt-plugin --ref main
codex plugin add contactout-chatgpt@contactout-tools

插件代码公开可审查，安装过程中不会把 API key 写入 GitHub。

Windows 安装方法
  1. 安装并打开 Windows 版 ChatGPT；没有安装时，在 PowerShell 运行下方的 winget 命令。
  2. 在 ChatGPT 中切换到 Codex，按 Ctrl + ` 打开内置 PowerShell 终端。
  3. 先运行 codex --version。能显示版本后，再运行上面的两条插件安装命令。
  4. 关闭所有 ChatGPT 窗口并重新启动，在 Settings → Plugins → Installed 中检查插件。
winget install --id 9PLM9XGG6VKS -s msstore

推荐选择 Windows native + PowerShell。若使用 WSL，配置保存在 Linux 的 ~/.codex，默认不会与 Windows 应用的 %USERPROFILE%\.codex 自动共享。

在 ChatGPT/Codex 的内置终端或 macOS Terminal 运行上面的两条插件命令，然后完全退出并重新打开 ChatGPT。
